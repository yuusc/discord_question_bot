# 匿名質問Discordボット

DiscordのDM（ダイレクトメッセージ）で `!q <質問内容>` と送ると、指定したチャンネルに**匿名で**質問を投稿するボットです。

---

## 動作イメージ

1. ユーザーがボットにDMを送る: `!q なぜ空は青いの？`
2. 指定チャンネルにボットが投稿: `【匿名の質問】なぜ空は青いの？`
3. ボットがDMで返信: `✅ 質問を匿名で投稿しました！`

---

## 必要なもの

- **Go** (バージョン 1.21 以上)
- **Discordアカウント**
- **Discordサーバー**（管理者権限があること）

---

## セットアップ手順

### ステップ 1: Goをインストールする

Goがインストールされているか確認します。ターミナル（コマンドプロンプト）で以下を実行してください。

```bash
go version
```

`go version go1.21.0 ...` のように表示されればOKです。  
表示されない場合は https://go.dev/dl/ からインストールしてください。

---

### ステップ 2: Discordボットを作成する

#### 2-1. Discord Developer Portalにアクセス

https://discord.com/developers/applications を開きます。  
Discordアカウントでログインしてください。

#### 2-2. アプリケーションを作成

1. 右上の「**新しいアプリケーション**」ボタンをクリック
2. 好きな名前を入力（例: `匿名質問Bot`）
3. 利用規約にチェックを入れて「**作成**」をクリック

#### 2-3. ボットを追加

1. 左メニューの「**Bot**」をクリック
2. ユーザ名に任意のユーザ名（ボット名）を入力

#### 2-4. ボットトークンをコピー

1. 「Bot」ページの「**トークン**」セクションで「**トークンをリセット**」をクリック
2. 「Botのトークンをリセットしますか？」には「**実行します！**」をクリック
3. 表示されたトークン（長い文字列）をコピーして**メモ帳などに保存**してください

> ⚠️ **重要**: トークンは絶対に他人に見せないでください。ボットを完全に乗っ取られます。

#### 2-5. Message Content Intentを有効化

同じ「Bot」ページを下にスクロールして「**Privileged Gateway Intents**」セクションを探します。

- 「**Message Content Intent**」を **ON** にする

「**変更を保存**」ボタンをクリックして保存します。

> ℹ️ これをONにしないと、ボットがDMのメッセージ内容を読めません。

---

### ステップ 3: ボットをサーバーに招待する

#### 3-1. 招待URLを生成

1. 左メニューの「**OAuth2**」→「**OAuth2 URLジェネレーター**」をクリック
2. 「**スコープ**」セクションで「**bot**」にチェック
3. 下に「**BOT PERMISSIONS**」が表示されるので以下にチェック:
   - `チャンネルを表示`
   - `メッセージを送る`
4. ページ下部の「**生成されたURL**」をコピー

#### 3-2. ボットを招待

1. コピーしたURLをブラウザのアドレスバーに貼り付けてEnter
2. 招待するサーバーを選択
3. 「**認証**」をクリック

Discordを開くとボットがサーバーのメンバーに追加されています。

---

### ステップ 4: 投稿先チャンネルのIDを取得する

#### 4-1. 開発者モードを有効化

1. Discordの左下の歯車アイコン（ユーザー設定）をクリック
2. 左メニューの「**<>開発者**」をクリック
3. 「**開発者モード**」を **ON** にする

#### 4-2. チャンネルIDをコピー

1. 質問を投稿させたいチャンネルを**右クリック**
2. 「**チャンネルIDをコピー**」をクリック

> ⚠️ **注意**: サーバー名を右クリックして出てくる「サーバーIDをコピー」とは**別物**です。必ずチャンネルを右クリックしてください。

---

### ステップ 5: ソースコードをダウンロードする

このリポジトリをダウンロードしてください。

```bash
git clone <リポジトリのURL>
cd discord
```

またはZIPでダウンロードして解凍し、そのフォルダをターミナルで開いてください。

---

### ステップ 6: 設定ファイルを作成する

プロジェクトのフォルダに `.env` というファイルを作成します。

**Macの場合:**
```bash
cp .env.example .env
```

**Windowsの場合:**
```cmd
copy .env.example .env
```

作成した `.env` ファイルをメモ帳などで開いて、ステップ2と4で取得した値を入力します。

```
BOT_TOKEN=ここにボットトークンを貼り付ける
TARGET_CHANNEL_ID=ここにチャンネルIDを貼り付ける
```

**入力例:**
```
BOT_TOKEN=*****
TARGET_CHANNEL_ID=1234567890123456789
```

> ⚠️ `.env` ファイルはGitに含まれないよう `.gitignore` で除外されています。トークンが外部に漏れることはありません。

---

### ステップ 7: 依存ライブラリをインストールする

プロジェクトのフォルダでターミナルを開き、以下を実行します。

```bash
go mod tidy
```

---

### ステップ 8: ビルドして起動する

#### ビルド（実行ファイルを作成）

```bash
go build -o discord-anon-bot .
```

#### 起動

**Macの場合:**
```bash
./discord-anon-bot
```

**Windowsの場合:**
```cmd
discord-anon-bot.exe
```

以下のように表示されれば起動成功です。

```
2024/01/01 12:00:00 ボットが起動しました。CTRL-C で終了します。
```

---

## 使い方

ボットが起動したら、DiscordでボットにDMを送ります。

| 操作 | コマンド |
|---|---|
| 質問を投稿する | `!q <質問内容>` |

**例:**
```
!q 新しいプロジェクトのアイデアを募集中です！何かありますか？
```

指定チャンネルに以下のように投稿されます：
```
【匿名の質問】新しいプロジェクトのアイデアを募集中です！何かありますか？
```

### エラーメッセージ一覧

| メッセージ | 意味 |
|---|---|
| `使い方: !q <質問内容>` | コマンドの形式が間違っています |
| `エラー: 質問内容を入力してください。` | `!q` の後に何も書いていません |
| `エラー: 質問を投稿できませんでした。` | 権限やチャンネルIDを確認してください |

---

## ボットを常時起動させる（オプション）

ターミナルを閉じるとボットも終了します。常時起動させるには以下の方法があります。

### Macの場合（バックグラウンド実行）

```bash
nohup ./discord-anon-bot &
```

停止させるには:
```bash
pkill discord-anon-bot
```

### Windowsの場合

タスクスケジューラやサービスとして登録することで常時起動できます。

## トラブルシューティング

### ボットがDMに返答しない

- Developer Portalで「Message Content Intent」がONになっているか確認
- ボットがサーバーに参加しているか確認

### `Unknown Channel` エラーが出る

- `.env` の `TARGET_CHANNEL_ID` がサーバーIDになっていないか確認（チャンネルを右クリックしてコピーする）
- ボットに `View Channels` と `Send Messages` の権限があるか確認

### `Invalid Token` エラーが出る

- `.env` の `BOT_TOKEN` が正しいか確認
- Developer Portalでトークンをリセットして再取得する
