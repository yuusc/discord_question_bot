# 匿名質問Discordボット

DiscordのDM（ダイレクトメッセージ）で `!q <質問内容>` と送ると、指定したチャンネルに**匿名で**質問を投稿するボットです。

---

## 動作イメージ

1. ユーザーがボットにDMを送る: `!q なぜ空は青いの？`
2. 指定チャンネルにボットが投稿: `【匿名の質問】なぜ空は青いの？`
3. ボットがDMで返信: `✅ 質問を匿名で投稿しました！`

---

## 必要なもの

- **Discordアカウント**
- **Discordサーバー**（管理者権限があること）
- **Ubuntu / WSL2 環境**（Goのインストールはセットアップスクリプトが自動で行います）

---

## セットアップ手順

### ステップ 1〜4: Discordの設定（先に済ませてください）

#### ステップ 1: Discord Developer Portalにアクセス

https://discord.com/developers/applications を開きます。  
Discordアカウントでログインしてください。

#### ステップ 2: アプリケーションを作成

1. 右上の「**新しいアプリケーション**」ボタンをクリック
2. 好きな名前を入力（例: `匿名質問Bot`）
3. 利用規約にチェックを入れて「**作成**」をクリック

#### ステップ 3: ボットを追加してトークンをコピーする

1. 左メニューの「**Bot**」をクリック
2. ユーザ名に任意のユーザ名（ボット名）を入力
3. 「**トークンをリセット**」をクリック →「**実行します！**」
4. 表示されたトークン（長い文字列）をコピーして**メモ帳などに保存**

   > ⚠️ **重要**: トークンは絶対に他人に見せないでください。ボットを完全に乗っ取られます。

5. 同じページを下にスクロールして「**Privileged Gateway Intents**」を探す
6. 「**Message Content Intent**」を **ON** にして「**変更を保存**」をクリック

   > ℹ️ これをONにしないと、ボットがDMのメッセージ内容を読めません。

#### ステップ 4: ボットをサーバーに招待する

1. 左メニューの「**OAuth2**」→「**OAuth2 URLジェネレーター**」をクリック
2. 「**スコープ**」セクションで「**bot**」にチェック
3. 下に「**BOT PERMISSIONS**」が表示されるので以下にチェック:
   - `チャンネルを表示`
   - `メッセージを送る`
4. ページ下部の「**生成されたURL**」をコピーしてブラウザで開く
5. 招待するサーバーを選択して「**認証**」をクリック

#### ステップ 5: 投稿先チャンネルのIDを取得する

1. Discordの左下の歯車アイコン（ユーザー設定）をクリック
2. 左メニューの「**<>開発者**」をクリック
3. 「**開発者モード**」を **ON** にする
4. 質問を投稿させたいチャンネルを**右クリック**
5. 「**チャンネルIDをコピー**」をクリック

   > ⚠️ **注意**: サーバー名を右クリックして出てくる「サーバーIDをコピー」とは**別物**です。必ずチャンネルを右クリックしてください。

---

### ステップ 6: ソースコードをダウンロードしてセットアップする

このリポジトリをダウンロードしてください。

```bash
git clone <リポジトリのURL>
cd discord
```

またはZIPでダウンロードして解凍し、そのフォルダをターミナルで開いてください。

ダウンロードしたフォルダでセットアップスクリプトを実行します。

```bash
bash setup.sh
```

スクリプトが以下を自動で行います：

| ステップ | 内容 |
|---|---|
| 1 | Go のインストール（未インストールの場合） |
| 2 | 依存ライブラリの取得 & ビルド |
| 3 | ボットトークンとチャンネルIDを入力 → `.env` 自動作成 |
| 4 | systemd サービスに登録（PC再起動後も自動起動） |
| 5 | 起動して動作確認 |

途中でステップ3・5で取得したトークンとチャンネルIDの入力を求められます。そのまま貼り付けてください。

---

### WSL2 をお使いの場合（自動起動について）

WSL2 では systemd がデフォルトで無効です。自動起動を有効にするには、スクリプト実行前に以下の設定をしてください。

1. ターミナルで以下を実行:
   ```bash
   sudo nano /etc/wsl.conf
   ```
2. 以下の内容を追加して保存（Ctrl+O → Enter → Ctrl+X）:
   ```
   [boot]
   systemd=true
   ```
3. PowerShell（Windowsのターミナル）で実行して WSL2 を再起動:
   ```
   wsl --shutdown
   ```
4. WSL2 を開き直して `bash setup.sh` を実行

> ℹ️ この設定をしない場合でも、スクリプトがボットをバックグラウンドで起動します。ただし PC を再起動すると止まります。

## 使い方

セットアップ完了後、DiscordでボットにDMを送ります。

| 操作 | コマンド |
|---|---|
| 質問を投稿する | `!q <質問内容>` |

`!q` の後の区切りは半角スペース・全角スペース・タブのいずれでも構いません。

**例:**
```
!q 新しいプロジェクトのアイデアを募集中です！何かありますか？
```

指定チャンネルに以下のように投稿されます：
```
【匿名の質問】新しいプロジェクトのアイデアを募集中です！何かありますか？
```

### エラーメッセージ一覧

| メッセージ | 意味 |
|---|---|
| `使い方: !q <質問内容>` | コマンドの形式が間違っています |
| `エラー: 質問内容を入力してください。` | `!q` の後に何も書いていません |
| `エラー: 質問を投稿できませんでした。` | 権限やチャンネルIDを確認してください |

---

## ボットの管理

```bash
# ログをリアルタイムで表示
journalctl -u discord-anon-bot -f

# 停止
sudo systemctl stop discord-anon-bot

# 再起動（設定変更後など）
sudo systemctl restart discord-anon-bot

# 自動起動を無効化
sudo systemctl disable discord-anon-bot
```

## トラブルシューティング

### ボットがDMに返答しない

- Developer Portalで「Message Content Intent」がONになっているか確認
- ボットがサーバーに参加しているか確認

### `Unknown Channel` エラーが出る

- `.env` の `TARGET_CHANNEL_ID` がサーバーIDになっていないか確認（チャンネルを右クリックしてコピーする）
- ボットに「チャンネルを表示」と「メッセージを送る」の権限があるか確認

### `Invalid Token` エラーが出る

- `.env` の `BOT_TOKEN` が正しいか確認
- Developer Portalでトークンをリセットして再取得し、`bash setup.sh` を再実行する
